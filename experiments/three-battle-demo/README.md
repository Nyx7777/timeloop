# 时间循环 · Three.js 三维战斗试验

独立的可玩表现原型：可旋转三维实验室、始终朝向镜头的角色棋子、固定二维单位卡片，以及全屏二维斩杀。

## 在线试玩

固定入口：<https://nyx7777.github.io/timeloop/three-battle-demo/>。直接打开即可，无需启动本地服务。2026-09-24 已发布 02 版实验室美术，公网 15 项浏览器流程检查通过。

## 启动

在安装了 Node.js 22.12+（或 24 LTS）的 Windows 电脑上，双击本目录的 `start-demo.cmd`。首次会按锁文件安装依赖，之后打开 <http://127.0.0.1:4173/>。

也可以在本目录运行：

```powershell
npm.cmd ci
npm.cmd run dev
```

这是本地网页应用，需要通过本地服务器运行；不要直接双击 `index.html`。服务仅监听本机。正式构建使用 `npm.cmd run build`，结果在 `dist/`，使用相对资源路径。

## 先这样试玩

1. 默认进入“时间断层实验室”。拖动棋盘旋转，滚轮缩放，右上角可按 45° 转向、俯视或复位。手机使用单指拖动、双指缩放。
2. 点击顶部 E1 行动卡，在完整卡片里选择“斩杀这个敌人”。会从三维棋盘切入“时序断裂”二维演出，结束后返回原镜头。
3. 可以使用“跳过演出”或 Esc；底部复选框可关闭演出。“演出预览”只播放效果，不消耗行动。
4. 选择移动后点击青色地格；每回合最多移动一次、攻击一次。攻击后不能再移动，结束回合执行敌方行动。
5. 实验场可“固化”，在下一时间线看到紫色分身重演。
6. 切换到“留下第一个自己”，按下方路线体验原项目第一关。

快捷键：`1` 移动、`2` 攻击、`3` 固化、空格结束回合；`Q/E` 转镜头，`R` 镜头复位。按钮获得焦点后空格保留浏览器原生按钮行为。

## 第一关验证路线

列 A—H 对应 x=0—7，行 1—8 对应 y=0—7。

- T1：从 A8 移动至 **B7**，攻击 **B6** 的 E1，再结束回合。本体死亡，留下录像。
- 进入 T2：分身先重演到 B7，攻击 B6，敌人剩 2 HP。
- 本体从 A8 移动至 **A6**，再攻击 B6 的 E1，触发斩杀并获胜。

T1 不显示实时 AI 的具体意图；T2 只显示实际记录过的历史。分身固定攻击原目标格，不自动寻找新的敌人。移动模式优先选择合法地格，避免立绘覆盖地格造成误选；顶部行动卡始终可用于选人。

## 场景与范围

| 场景 | 来源 | 用途 |
|---|---|---|
| 时间断层实验室 | 自定义 8×8、3 敌人、3 条时间线配置 | 快速试验旋转、障碍淡化、牌面与斩杀 |
| 留下第一个自己 | `game/content/levels/first_echo.tres` 的出生点、墙体、HP、伤害、移动力、命数 | 验证基础战斗与 T1→T2 分身协作 |

角色 PNG 是项目已验收本体、同轮廓分身和时间错位研究员的独立副本。地台、设备、光照、时间空洞与漂浮碎片由 Three.js 生成；二维牌面和斩杀由 HTML/CSS 展示。

这是 D-037 的独立视觉试验，不是正式内核移植。没有移植六关完整规则、普通攻击击退、单位碰撞伤害、扰动清醒、宏观路线与存档。实验场空洞仅作为不可通行地形。现有 `game/` Godot 工程与旧 H5 Demo 继续保留原角色和职责。

`src/battle.js` 是本原型的单一状态来源；所有命令先结算，再输出事件供 `src/scene.js` 与 `src/main.js` 播放。斩杀、跳过、关闭演出都不会再次施加伤害。实际正式接入前仍须对 Godot 事件契约、完整规则及手机设备性能做专项评审。
