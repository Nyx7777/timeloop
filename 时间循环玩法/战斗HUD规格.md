# 战斗 HUD 规格

> 创建日期：2026-08-04  
> 用途：正式战斗界面的完整信息层级、元素清单和布局约束。后续所有 UI 设计和实现以本文档为基准。  
> 画幅基准：竖版手机 390×844（逻辑分辨率）。  
> 视角方向（已确认）：近俯视微倾斜（约 10-15° 偏离正上方），格子接近正方形，墙体露出一丝侧面，8×8 完整可见不裁切。参考 `12_ui_near_topdown_max_complexity.png`。  
> 视觉方向：明亮实验室像素风（前期章节），棋盘外围暗紫碎裂边框表现时间侵蚀，可随章节逐步转暗但不能遮挡战术信息。
> M5 状态说明：M4 已验证当前布局、触控和首批皮肤可用，但顶部栏、按钮与时间状态仍按产品原型看待；M5.0A—C 将其升级为可对外测试的正式视觉与信息系统，几何基线除非评审明确否决，否则保持稳定。

## 1. 画面分区

```
┌─────────────────────────┐
│       顶部 HUD          │  ≈ 6% 屏高
├─────────────────────────┤
│     行动序列条          │  ≈ 4% 屏高
├─────────────────────────┤
│                         │
│                         │
│      战场棋盘区         │  ≈ 68% 屏高
│   （8×8 近俯视方格）   │
│                         │
│                         │
├─────────────────────────┤
│     底部操作区          │  ≈ 22% 屏高
└─────────────────────────┘
```

- 战场棋盘区是绝对主角，占画面高度的 65-70%。
- 顶部 HUD + 行动序列条合计不超过 10%。
- 底部操作区包含四个固定按钮和情境提示条。
- Boss 战时顶部 HUD 下方额外展开 Boss 血条（挤压棋盘约 3%）。

## 2. 顶部 HUD（常驻）

| 位置 | 内容 | 格式示例 | 说明 |
|------|------|----------|------|
| 左 | 时间线编号 | T2/3 | 当前第几条时间线 / 总命数 |
| 中 | 回合数 | 回合 4 | 当前回合 |
| 右 | 剩余命数 | ◆◆◆ | 用图标表示，直观可数 |

### 补充状态（紧凑次行或融入顶栏）

| 内容 | 何时显示 | 说明 |
|------|----------|------|
| 时间状态汇总 | 始终 | T1 可显示“未知时间”；T2+ 按敌人实际状态显示“固定 2 · 清醒 1”，不能用单一全局标签掩盖混合状态 |
| 固定历史标记 | 存在固定敌人 | 完整时钟图标 + 橙色数字，和棋盘固定意图一致 |
| 清醒标记 | 存在清醒敌人 | 断裂时钟图标 + 金色数字，表示这些敌人将在玩家行动后实时决策 |

## 2.5 行动序列条

显示本回合所有单位的出手先后顺序，当前行动者高亮。

```
┌────────────────────────────────────────┐
│ [分身T1] [分身T2] [▶本体] [敌A] [敌B] [敌C] │
└────────────────────────────────────────┘
```

| 属性 | 说明 |
|------|------|
| 位置 | 顶部 HUD 正下方，横向排列 |
| 形式 | 小圆形头像/图标 + 阵营色边框；敌人附稳定编号 E1、E2…… |
| 当前行动者 | 放大 + 白色箭头指示 + 高亮边框 |
| 已行动 | 半透明灰化 |
| 未行动 | 正常亮度 |
| 阵营色 | 紫色=分身、青色=本体、红色=敌人 |
| 固定敌人 | 完整时钟角标 + 橙色内圈，与棋盘固定意图一一对应 |
| 待清醒敌人 | 断裂中的时钟角标，提示“下回合清醒” |
| 已清醒敌人 | 金色断钟角标 + 特殊边框，不再显示固定意图 |
| 交互 | 点击头像可高亮对应棋盘单位；点击敌人头像同时只聚焦该敌人的路径和攻击，其余敌人意图降为低透明度 |

### 出手顺序规则

固定顺序，每回合不变：
1. **分身阶段**：T1 → T2 → ... （最旧到最新）
2. **玩家阶段**：本体行动
3. **敌方阶段**：按敌人编号顺序执行

序列条让玩家始终清楚：
- "现在轮到谁" — 当前高亮
- "我之前还有几个分身要动" — 左侧紫色数量
- "我之后有几个敌人要动" — 右侧红色数量

## 2.7 Boss 血条（仅 Boss 战显示）

普通关卡不显示此区域；进入 Boss 战时在行动序列条下方展开。

```
┌─────────────────────────────────────┐
│  [Boss 名]              ████████░░  │
│  [特殊状态标记]          HP 48/120  │
└─────────────────────────────────────┘
```

| 属性 | 说明 |
|------|------|
| 位置 | 行动序列条下方，全宽横条 |
| 高度 | ≈ 3% 屏高，仅 Boss 战出现 |
| 内容 | Boss 名称 + HP 条（分段显示阶段） + 数值 |
| 阶段分段 | HP 条按 Boss 阶段分割（如 3 段），当前段高亮 |
| 特殊状态 | Boss 独有 Buff/状态图标排列在名字下方（如：时间意识、分身劫持） |
| 颜色 | 深红底 + 亮红填充，阶段分割线用金色 |

### Boss 头顶信息简化

Boss 在棋盘上仍然显示红橙色底座，但**不挂头顶 HP 条**（由顶部专属血条承担），避免遮挡周围格子信息。普通敌人仍保留头顶扁条 HP。

## 3. 棋盘单位层

棋盘上需要同时可辨识的实体类型：

| 单位 | 主色 | 视觉特征 | 出现条件 |
|------|------|----------|----------|
| 本体 | 青色 teal | 高亮轮廓、实心 | 始终 |
| 分身 | 紫色 | 半透明 + 残影偏移 | T2+ |
| 普通敌人 | 红橙 | 实心、红色底座高亮 | 始终 |
| 不可通行设备 | 灰蓝 | 单格立柱、服务器机柜等有明确实验室用途的实体，露出顶面与正面 | 关卡阻挡数据决定 |
| 时间空洞 | 黑紫 | 漩涡/深渊效果 | 关卡数据决定 |

### 单位辨识原则

- 所有单位必须在颜色 + 轮廓 + 动态三个维度中至少两个可区分。
- 分身之间用编号或时间线颜色渐变（T1 浅紫、T2 深紫）区分。
- 分身无 HP 条（不可干涉的时间投影，无生命值）。

### 头顶 HP 条

| 单位 | HP 条样式 | 说明 |
|------|----------|------|
| 本体 | 青色底 + 绿色填充，略宽于敌人 | 始终显示在本体头顶 |
| 普通敌人 | 红色底 + 红色填充，扁条 | 始终显示在敌人头顶 |
| Boss | 不挂头顶条 | 由顶部专属 Boss 血条承担（§2.7） |
| 分身 | 无 | 不可被伤害，不显示 |

## 4. 棋盘叠加层（战术信息）

这是信息最密集的部分。每种叠加有明确的触发时机和视觉规则：

### 4.1 回合开始自动展示（T2+ 已知时间）

| 叠加 | 颜色 | 形式 | 说明 |
|------|------|------|------|
| 分身本回合路径 | 紫色 | 虚线箭头沿格子 | 每个分身各一条 |
| 分身火线（下回合攻击格） | 紫色 | 格子边框 + ⚠ | 本体需避开 |
| 固定敌人编号与状态 | 橙色 | E1/E2 标签 + 完整时钟 | 与行动序列头像一一对应 |
| 固定敌人移动路径 | 橙色 | 从当前格出发的虚线箭头 | 必须显示完整路径，而非只标终点 |
| 固定敌人移动终点 | 橙色 | 终点圆圈 | 与路径使用同一编号或图形编码 |
| 固定敌人攻击 | 红色 | 从移动后终点发出的攻击线 + 危险格 + 伤害 | 不能错误地从回合开始位置出线 |
| 固定敌人等待 | 橙色 | 原地沙漏/“等待” | 没有移动或攻击也必须明确告知行为 |
| 已清醒敌人 | 金色 | 断钟 + `?` | 不展示实时 AI 结果，避免泄露未知时间 |

只为仍处于固定历史的敌人展示确定路径与攻击。多个敌人意图交叉时，默认保留全局概览；玩家点击行动序列里的 E1/E2 后，只强化对应敌人的整条路径、终点和攻击，其余敌人意图降低透明度，但单位本身仍保持可见。

### 4.2 玩家操作时动态展示

| 叠加 | 颜色 | 形式 | 触发 |
|------|------|------|------|
| 可移动范围 | 青色半透明 | 填充菱形格 | 点击"移动"或点击本体 |
| 分身最终占位格（禁止停留） | 紫色 + ✕ | 格子禁止标记 | 选择移动终点时 |
| 可攻击目标 | 红色边框 | 目标格高亮 | 点击"攻击" |
| 击退落点预览 | 黄色箭头 | 从目标指向落点 | 攻击确认前 |
| 击退推入空洞警告 | 黄色 + 骷髅 | 落点处死亡标记 | 落点为时间空洞时 |
| 击退碰撞预览 | 橙色闪电 | 被占据落点显示双方受伤标记 | 落点已有单位时 |

### 4.3 结算中即时反馈

| 叠加 | 颜色 | 形式 | 触发 |
|------|------|------|------|
| 伤害数字 | 白色/红色 | 弹出数字 | 攻击命中 |
| 扰动环 | 波纹扩散 | 从被击退敌人向外 | 击退触发扰动 |
| 死亡碎裂 | 镜片碎裂粒子 | 原位爆散 | 单位死亡 |
| 固化消散 | 轻快光粒子 | 分身化为光点 | 主动固化成功 |

### 4.4 战场美术越界与信息优先级

战场采用固定近俯视视角，但透视与立体感不能造成格子误判。所有棋盘内美术遵循以下显示优先级：

纹理密度、同角色变体派生、Godot 导入缓存和实载验收流程统一见《战场美术素材规范》；本节只规定视觉占格与信息遮挡。

1. 操作目标、危险格、路径、火线和击退结果。
2. 单位、HP、行动顺序与敌人意图。
3. 地形功能、占位范围和不可通行语义。
4. 场景美术、材质与空间纵深。
5. 纯装饰与氛围效果。

低优先级元素不得长期遮挡高优先级信息。一个逻辑上只占一格的实体，不能在静态画面中看起来占据两格。

| 元素类型 | 允许超出逻辑格 | 强制要求 |
|---|---:|---|
| 普通地砖、时间空洞 | 0 | 完全限制在本格，边界与危险语义始终清楚 |
| 棋盘内单格立柱、服务器等障碍 | 向上最多 20—25% 格高 | 可见主体宽度不超过约 90% 格宽；底座和所属格必须明确 |
| 普通单位 | 向上最多约 30% 格高 | 脚底锚点、底座或所属格轮廓始终可辨；不能永久遮挡相邻单位与标记 |
| 武器、攻击和受击动画 | 可短暂大幅越界 | 默认不超过 0.5 秒；不能改变点击热区，也不能让结果预览消失 |
| 大型设备、Boss | 按真实逻辑占位 | 美术覆盖 1×2、2×2 等多格时，规则层必须使用相同占位范围 |
| 棋盘外围装饰 | 不限制 | 不得进入可交互棋盘或遮挡 HUD |

#### 动态避让

- 尺寸压缩是第一选择，动态透明只作为安全网。
- 当越界部分遮挡相邻格的单位、移动/攻击目标、危险预告、分身路径、火线或击退落点时，可将越界部分临时降至 35—45% 不透明度。
- 动态避让不得改变逻辑占位、点击区域或事件顺序；没有关键信息被遮挡时保持正常不透明度，避免持续闪烁。
- 棋盘内使用“战术压缩版”素材；完整高度版本优先用于棋盘边缘、背景实验室和非交互演出。

#### 新素材接入检查

1. 玩家能否在 1 秒内判断素材属于哪一格？
2. 素材看起来占几格，是否与规则占位一致？
3. 最复杂帧下，是否遮挡路径、危险格、单位或结果预览？
4. 缩小、裁切或动态透明后，是否仍保留足够的身份特征？

前三项任一不通过，素材不得以“更有立体感”为由进入正式战场。

## 5. 底部操作区

### 5.1 固定四按钮

采用固定四按钮布局，不可用时变灰但不隐藏（维持肌肉记忆）。

```
┌──────┬──────┬──────┬──────┐
│      │      │      │      │
│ 移动 │ 攻击 │ 固化 │ 结束 │
│      │      │      │      │
└──────┴──────┴──────┴──────┘
```

| 按钮 | 图标 | 边框色 | 可用条件 | 不可用表现 |
|------|------|--------|----------|-----------|
| 移动 | 方向箭头 | 青色 | 玩家阶段且本回合未移动 | 灰色 + 半透明 |
| 攻击 | 剑 | 红色 | 玩家阶段且相邻有合法目标 | 灰色 + 半透明 |
| 固化 | 水晶 | 紫色 | 关卡已解锁 + 剩余命 > 1 | 灰色 + 半透明 |
| 结束回合 | 沙漏 | 金色 | 玩家阶段 | 灰色 + 半透明 |

#### 正式按钮状态矩阵（M5.0A）

| 状态 | 视觉与反馈要求 |
|------|----------------|
| 默认 | 图标、文字与阵营语义清楚，轮廓强度低于选中态 |
| 按下 | 产生明确下沉/压缩和短促音画反馈，松手后再执行，避免误触无反馈 |
| 选中 | 高亮边框、底色和情境提示同步变化；不能只依赖颜色 |
| 禁用 | 灰显但不隐藏，仍可辨认原功能；点击时可给出简短不可用原因 |
| 锁定 | 在禁用基础上增加锁图标或条件文案，用于尚未解锁的固化/能力 |
| 教程聚焦 | 目标按钮保持正常亮度并有节奏性描边，其余按钮降权但仍可识别 |

M5.0A 需同时定义按钮、顶栏、序列条、提示条和弹窗的字体、九宫格面板、描边、图标及动效 Token。当前 M4 皮肤可作为布局参考，但不直接视为最终发布资产。

### 5.2 情境提示条

按钮上方可浮现一行情境文字，用于确认操作：

| 场景 | 提示内容 | 操作 |
|------|----------|------|
| 选择移动目标后 | "点击目标格移动" | 点格确认 / 点按钮取消 |
| 选择攻击目标后 | "点击目标攻击（击退→东）" | 点目标确认 |
| 确认固化 | "确认固化？将消耗 1 条命" | 再次点击确认 / 其他操作取消 |

## 6. 弹窗层（覆盖棋盘）

全屏半透明遮罩 + 居中内容卡片，打断当前操作。

| 触发条件 | 标题 | 内容 | 操作 |
|----------|------|------|------|
| 本体死亡（非最后一命） | 时间线断裂 | "录像已保存，新分身将在下一时间线重演" | [继续] |
| 主动固化 | 固化完成 | "当前行动已锁定为分身录像" | [继续] |
| 即时胜利 | 任务完成 | 通关统计（回合数、时间线数、坍缩值） | [合并回放] / [返回] |
| 最后一命死亡 | 时间崩塌 | "所有时间线同步坍缩" | [重试] / [退出] |

## 7. 最复杂一帧基准

用于验证视觉不过载的极端场景。

### 7.1 普通关最复杂帧

**T3、回合 4、已知时间、玩家正在选择攻击目标：**

同时存在于画面上的元素：
- 顶部 HUD：T3/3 · 回合 4 · ◆◆◆ · 已知时间
- 行动序列条：[T1灰][T2灰][▶本体][敌A][敌B][敌C]
- 本体 ×1（青色）
- 分身 ×2（紫色，各带路径箭头 + 火线标记）
- 敌人 ×3（红橙，各带橙色移动终点 + 红色攻击格）
- 时间空洞 ×2（黑紫漩涡）
- 墙体 ×4-6
- 本体可攻击范围红框 ×1-3
- 选中目标后的黄色击退落点 ×1
- 底部四按钮（攻击高亮，其余灰色）+ 情境提示

**总计：** 7-8 个单位 + 10-15 个叠加标记分布在 64 格上。

### 7.2 Boss 战最复杂帧

**T3、回合 6、已知时间、Boss 阶段转换后、玩家选择攻击：**

在普通关所有元素基础上增加：
- 顶部 Boss 血条（名称 + 分段 HP + 特殊状态图标 ×2）
- Boss 本体占 2×2 格或 1 格但精灵尺寸更大
- Boss 攻击范围预告（大面积红色覆盖，可能 3×3 或十字形）
- 行动序列条多一个大号 Boss 头像图标

**验证要点：** Boss 血条 + 行动条 + HUD 三层叠加后，棋盘仍能保持 ≥ 60% 屏高。

### 可读性检验标准

1. 任意单位的颜色在 1 秒内可辨识阵营（本体/分身/敌人）。
2. 危险格（红色、紫色火线）与安全移动范围（青色）不会混淆。
3. 时间空洞的视觉权重高于普通地砖，玩家不会误入。
4. 击退方向箭头清晰指向落点，不被单位遮挡。
5. 分身路径箭头与敌人意图箭头通过颜色（紫 vs 橙红）明确区分。
6. 在最复杂帧下，棋盘上空白格仍占 40% 以上面积。

## 9. 中后期扩展预留

以下元素最初作为中后期预留；其中扰动清醒已纳入 M5.0B，其他项目仍按各自状态决定是否实现。

### 9.1 底部操作区演进方向 `[待细化]`

当前四按钮（移动/攻击/固化/结束回合）是前期灰盒的最小集。后续演进方向：

- **移动 + 攻击可能合并**：大部分情况下攻击发生在移动之后（攻击后移动是特殊能力），两者可以合为一个"行动"流程——点格移动后自动切换到攻击选择。
- **推拉绑定攻击/额外行动**：不作为独立按钮，而是攻击命中后或特殊技能的附加效果。
- **特殊技能/道具**：当装备提供额外主动能力时，底部需要支持更多选项。可能方案：攻击按钮长按展开技能轮盘、底部第二行快捷栏、或根据装备动态替换按钮。
- **重开当前时间线**：中期解锁能力，需要一个入口。候选位置：第五按钮（底部缩窄现有四个）、暂停菜单内、长按"结束回合"展开。`[待定]`

具体方案在 Build 系统设计完成后确认。当前布局按四按钮实现，预留底部操作区可纵向扩展到两行的空间。

### 9.2 扰动清醒表现 `[M5.0B 已确认待实现]`

敌人被扰动后不会立刻改写已经展示的行为，而是从下一回合脱离固定历史。表现必须严格对应规则时序：

| 时点 | 棋盘表现 | HUD / 文案 | 意图处理 |
|------|----------|------------|----------|
| 扰动触发瞬间 | 从目标扩散断裂时钟波纹/锁链断裂效果 | “已扰动·本回合行为仍已锁定” | 保留原路径、终点和攻击，不得立即消失或改变 |
| 当前回合剩余阶段 | 敌人附“下回合清醒”过渡徽记 | 行动序列显示断裂中的时钟角标 | 继续执行已锁定意图 |
| 下一回合开始 | 敌人附金色断钟与 `?` | 序列头像使用清醒特殊边框；顶部计入“清醒 N” | 不显示固定意图；玩家结束行动后按当前战场实时决策 |
| 当前时间线后续回合 | 持续显示清醒状态 | 顶部与序列持续保留清醒编码 | 继续实时决策，不重新回到本时间线的固定状态 |
| 时间线结束 | 无额外战斗内承诺 | 新行为写入历史 | 下一条时间线按改写后的历史重新判断固定前缀 |

普通敌人、精英和 Boss 可以有不同的清醒动画，但必须共享断钟图标、金色状态和上述时序，避免每类敌人形成不同规则暗示。

### 9.3 Buff/Debuff 状态图标 `[确认需要]`

单位可能携带的持续效果（中毒、燃烧、护盾、减速等）：

| 属性 | 说明 |
|------|------|
| 位置 | 单位 HP 条下方，小图标横排（最多显示 3-4 个，超出折叠为"+N"） |
| 形式 | 16×16 像素图标 + 剩余回合数小字 |
| 颜色 | 增益绿色边框、减益红色边框 |
| 回合末结算 | 结算瞬间对应图标闪烁 + 飘字（如 "-3 毒"） |

### 9.4 已砍掉 / 不进 HUD

| 项目 | 原因 |
|------|------|
| 监视技能 UI | 玩法层面大概率不做监视了 |
| 坍缩值显示 | 只影响宏观叙事，不在战斗 HUD 展示 |
| 冷却/弹药细节 | 做到 Build 系统时再定义，当前不预留固定位置 |
| 回合上限/奖励倒计时 | 后续再做，可在回合数旁叠加倒计时色变 |
