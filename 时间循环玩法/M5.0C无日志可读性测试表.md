# M5.0C 无日志可读性测试表

> 版本：2026-08-09 首个候选  
> 目标：验证玩家不查看日志时，能否在 3 秒内读懂固定敌人的移动、攻击、等待、扰动对象与清醒时点。

## 测试方式

1. 打开 Godot 主场景，点击右上角 `≡`，在“**M5.0C · 2—3 秒无日志读图**”中选择场景。
2. 点击“进入 M5.0C · 只读读图评审”。工具会关闭菜单，仅显示真实战斗 HUD 和棋盘。
3. 3 秒后画面自动遮罩。测试者先回答遮罩上的问题，再点击“显示对照答案”。
4. 记录是否答对、第一眼错误点和主观信心。不要用战斗日志、开发者口头解释或提前查看答案。
5. 每名测试者第一次结果最有价值；重复查看只用于定位问题，不覆盖首次记录。

## M5.0C 门禁

- 六个代表场景均能完成首次 3 秒测试，不需要打开日志。
- 360×800、390×844、430×932 均无裁切、误触或关键遮挡。
- 若同一信息在多名测试者中反复误读，先修正信息层级或视觉表达，再决定是否关闭 M5.0C。
- M5.0C 只验证战斗内可读性；不在本阶段加入新战斗规则、Boss 规则或战斗外宏观系统。
